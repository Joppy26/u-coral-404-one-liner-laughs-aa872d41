Entry for the [One-Liner Laughs](https://make.fun/bounty/u-coral-404-one-liner-laughs-aa872d41) bounty on make.fun.

A deterministic program that writes one funny single-line joke (max 200
characters) to `/output/entry.txt`. No randomness, no clock, no network, no
model calls: the joke is a fixed string, so every run produces identical
output.

## Run

```sh
python3 main.py
```

## The joke

> My smart fridge kept judging my midnight snacks, so I unplugged it. Now we both eat in the dark.

## Why it works

The setup gives the fridge a personality: a smart appliance that "judges"
feels like a roommate, not a machine. The punchline then flips the revenge:
unplugging it was supposed to silence the judge, but "we both eat in the
dark" turns the punishment back on the owner, because a dead fridge is dark
inside too.
